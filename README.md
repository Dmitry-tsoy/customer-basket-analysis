# customer-basket-analysis
Customer basket activity analysis using Python, pandas and Jupyter Notebook.

# Анализ активности пользователей в корзине

## Цель

Исследовать активность пользователей при добавлении товаров в корзину и выявить закономерности, связанные с пользователями, товарами и временем.

В рамках проекта проведены:

- проверка качества данных;
- анализ пользователей;
- анализ товаров;
- временной анализ.

**Важно:** датасет содержит события добавления товаров в корзину, а не покупки. Поэтому результаты отражают активность корзины, а не продажи.
В проекте используются синтетические данные.

## Данные

Датасет состоит из двух таблиц: `customers` и `basket`.

### `customers`

- `customer_id` — ID пользователя;
- `sex` — пол;
- `age` — возраст;
- `tenure` — срок взаимодействия пользователя с сервисом (мес.).

### `basket`

- `customer_id` — ID пользователя;
- `product_id` — ID товара;
- `basket_date` — дата события;
- `basket_count` — количество событий добавления товара в корзину.

## Вывод

Пол, возраст и срок взаимодействия с сервисом практически не влияют на активность добавления товаров в корзину.

Отдельные товары заметно популярнее остальных и значительно чаще добавляются в корзину.

С 25 по 28 мая наблюдается выраженный всплеск активности. Значительная часть добавлений нескольких популярных товаров пришлась именно на этот период.

Определить точную причину всплеска без дополнительной информации о товарах, скидках и маркетинговых активностях невозможно.

## Рекомендации

- Дополнительно изучить товары, которые чаще всего добавляются в корзину, особенно в период всплеска активности.
- Проверить, были ли с 25 по 28 мая акции, скидки или маркетинговые кампании.
- Для более глубокого анализа добавить данные о категориях товаров, ценах и фактических покупках.
